    How loss was measured

    • Land cover: my own LULC classification for 2020 (EUDR cut-off: 31 Dec 2020) and 2025.
    • Loss: any pixel in a vegetation class in 2020 that is no longer in a vegetation class in 2025.
    • Zonal summary: loss and retained-vegetation hectares per plantation and per 10 km buffer, in a projected CRS.
    • Flags read "potential risk: requires further review", never "deforested".
